# Sistema de Gestão de Ordens de Serviço e Manutenção de Equipamentos

Projeto acadêmico desenvolvido em Java para gerenciamento do ciclo de manutenção de equipamentos.

## Tecnologias previstas

- Java
- Maven
- SQLite
- JDBC
- JUnit
- NetBeans

## Arquitetura

O projeto utiliza arquitetura em camadas:

- Presentation
- Application
- Domain
- Infrastructure
